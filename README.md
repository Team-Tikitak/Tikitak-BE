## 📖 프로젝트 소개
### 우리 팀이 탁! 맞는 순간, 티키탁
티키탁(Tiki-Tak) 은 대학생의 팀 프로젝트 과정의 순간들을 함께 기록하고 회고하는 팀 단위 아카이브 서비스입니다.

- 팀원과 함께 찍은 사진을 피드로 업로드하고 팀원을 태그할 수 있습니다.
- 지도에서 팀의 추억이 담긴 장소 핀을 한눈에 확인할 수 있습니다.
- 매일 바뀌는 데일리 질문에 팀원들과 함께 답하며 소통할 수 있습니다.
- 홈 대시보드에서 팀 활동 통계와 멤버 조합별 추억을 볼 수 있습니다.

## 📁 패키지 구조

```
src/main/java/kusitms/spin/tikitak/
├── controller/          # API 엔드포인트
│   ├── auth/            # 인증 (OAuth, 토큰)
│   ├── dailyquestion/   # 오늘의 질문
│   ├── feed/            # 피드 CRUD, 반응, 댓글
│   ├── home/            # 홈 대시보드
│   ├── map/             # 지도 핀
│   ├── me/              # 내 정보 관리
│   ├── media/           # 미디어 업로드
│   ├── place/           # 장소 검색 (카카오맵)
│   ├── system/          # 서버 상태 확인
│   └── team/            # 팀 관리
├── domain/              # JPA 엔티티
├── global/              # Security, R2, KakaoMap 등 config 설정, 공통 응답, 예외 처리
├── repository/          # Spring Data 레포지토리
└── service/             # 비즈니스 로직
```

## 🔑 주요 기능

### 인증
- Google, Kakao, Apple OAuth 2.0 로그인
- 모바일 딥링크 OAuth 플로우 지원
- JWT Access / Refresh Token 관리

### 피드
- 이미지 1~10장 피드 작성 (장소, 날짜, 멤버 태그)
- 이모지 반응 (FeedReaction)
- 이미지 위 좌표 기반 댓글 (FeedComment)
- 장소·지역·유형·태그 멤버 기준 필터링
- 커서 기반 페이지네이션

### 팀
- 팀 생성·조회·수정, 멤버 초대 및 관리
- 팀 초대 코드, 초대 QR 지원

### 데일리 질문
- 매일 새 질문 제공
- 하루 1회 답변, 답변은 피드로 저장

### 지도
- 카카오맵 API 장소 검색 
- 팀 피드가 기록된 장소를 지도 핀으로 표시
- 핀마다 최신 피드 썸네일 미리보기

### 홈 대시보드
- 월별 출석 순위 (Best Attendance)
- 모든 팀원이 태그된 피드 모음
- 멤버 조합별 추억 하이라이트
- 지역별 추억 그룹핑
- 월별 랜덤 추천 장소

### 미디어
- Presigned URL 기반 S3/R2 직접 업로드
- 업로드 완료 후 상태 전환 및 검증
- 삭제된 미디어 배치 정리
